# Counter-Strike 1.6 · de_dust2（网页版）

纯前端 3D FPS，无需安装、无需联网、无需构建工具。用 Three.js 渲染，
地图、贴图、音效全部由代码程序化生成（没有任何外部素材文件）。

## 运行

直接双击 `index.html` 即可（Chrome / Edge / Firefox 等现代浏览器）。
进入主菜单后点「进入战场」，然后点击画面锁定鼠标。

## 玩法

- T（恐怖分子）进攻：把 C4 安放在 A 或 B 包点，守住 40 秒。
- CT（反恐精英）防守：阻止安放，或在爆炸前拆除（按住 E；有拆弹器 5 秒，没有 10 秒）。
- 消灭对方全部成员同样赢下回合。先赢到设定回合数的一方获得比赛胜利。

|---|---|---|---|
| W A S D | 移动 | 鼠标左键 | 射击 / 投掷手雷 |
| 鼠标 | 瞄准 | 鼠标右键 | AWP 开镜 / 轻抛手雷 |

主菜单里有「左右移动」开关，可以把 A / D 的方向对调。

## 经济与购买

起始 $800，上限 $16000。回合开始 **20 秒内**、站在**自家出生区**、且**存活**时按 `B` 打开购买菜单：
数字键选分类 → 数字键买东西，`0`/退格返回，`B`/`Esc` 关闭（也可以直接用鼠标点）。

| 收入 | 金额 |
|---|---|
| 击杀 | 按武器：步枪 $300 / AWP $100 / 霰弹枪 $900 / 匕首 $1500 |
| 灭队取胜 | $3250 |
| 炸弹爆炸（T）/ 成功拆弹（CT） | $3500 |
| 时间到（CT 守住） | $3250 |
| 安放 C4 / 拆除 C4 | $300 |
| 输掉回合（连败递增） | $1400 → $1900 → $2400 → $2900 → $3400 |

**活着过回合会保留武器、护甲和拆弹器**（弹药补满），阵亡后下回合回到手枪 + 匕首。

可买：手枪（Glock / USP / 沙鹰）、MP5、M3、Galil / FAMAS、AK-47 / M4A1、AWP、
防弹衣 $650、防弹衣+头盔 $1000（头盔能削减爆头伤害）、拆弹器 $200（CT）、
高爆手雷 $300、闪光弹 $200（可带 2 颗）、烟雾弹 $300。

## 手感说明

- 后坐力用 `recoilV / recoilH / ramp`：连发越久视角抬得越高（AK 打完一梭子约上抬 6°），需要自己往下压枪。
- 散布用 `perShot / spreadMax / recover`：站在原地一直突，散布会累积到上限（AK 约为基础值的 47 倍），
  停火约 1.5 秒后恢复精度。准星开合就是真实散布角在屏幕上的投影，所见即所得。
- 护甲会吸收伤害，头盔把爆头伤害降到 45%。

## 机器人

`js/bots.js` 里的机器人使用栅格 A* 寻路 + 视线检测 + 状态机（推进 / 交火 /
守点 / 安放 / 拆弹 / 听声侦查）。四档难度只改反应时间、瞄准误差、转身速度、
压枪能力与听觉范围，行为逻辑一致。机器人和玩家共用同一套经济与散布模型：
钱不够时只买护甲，钱够了买步枪 / 头盔 / 拆弹器 / 手雷；被闪光弹闪到会停火，
也看不穿烟雾；交火中偶尔会往你身上扔高爆雷。A* 每帧限流 2 条路径，5v5 不掉帧。

## 文件结构

```
index.html        页面、HUD、购买菜单、菜单、样式
three.min.js      Three.js（本地副本，离线可用）
js/textures.js    程序化贴图（沙墙、沙地、木箱、铁门、弹孔、火焰…）
js/map.js         de_dust2 简化布局、栅格化建墙、碰撞体、射线检测、购买区
js/phys.js        角色物理（AABB 碰撞、台阶、CS 式加减速与跳跃）
js/audio.js       WebAudio 合成音效（枪声、脚步、爆炸、C4 滴答…）
js/weapons.js     武器数值 + 购买表 + 第一人称手部/枪械模型
js/buy.js         购买菜单（按键路由与渲染）
js/nade.js        投掷物：抛物线 + 反弹 + 引信，HE / 闪光 / 烟雾（烟雾真的挡视线）
js/bots.js        A* 寻路、角色模型与动画、机器人 AI 与购买决策
js/game.js        主循环、玩家、回合与经济、命中判定、特效、HUD、雷达
js/selftest.js    自动化自检（只有带 ?selftest=1 时才加载）
```

## 调试用参数

`index.html?autostart=1&max=3&diff=hard&team=T&size=5` 可跳过菜单直接开局
（`max` 获胜回合、`diff` 难度、`team` 阵营、`size` 每队人数）。

`index.html?selftest=1` 会自动开局并跑一遍自检，把 PASS / FAIL 直接显示在屏幕中央：
后坐力与散布是否生效、开枪后画面是否仍在渲染、出生点是否会卡进箱子、A/D 与雷达朝向、
购买与经济（连败奖金、携带上限、钱不够）、手雷与烟雾遮挡、bot 购买、观战视角。
